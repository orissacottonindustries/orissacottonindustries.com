# Orissa Cotton Industries Website

Official static website for Orissa Cotton Industries.

Domain: https://orissacottonindustries.com/

## Files
- `index.html` — website content and SEO metadata
- `styles.css` — responsive visual design
- `script.js` — mobile menu and footer year
- `robots.txt` — search engine crawler instructions
- `sitemap.xml` — sitemap for Google Search Console
- `favicon.svg` — browser tab icon
- `CNAME` — custom domain for GitHub Pages

- `logo.png` — Orissa Cotton Industries brand logo
